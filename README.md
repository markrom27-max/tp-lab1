# Этап 2 — контейнер и меню

Откройте ConferenceLab.sln в Visual Studio 2022. Выберите Debug x64 и нажмите Ctrl+F5.

Добавлены Keeper на динамическом массиве Base**, класс Conference, глубокое копирование, перегрузка операторов и пользовательское меню. Доступны добавление, просмотр, фильтрация, изменение, удаление, копирование и переименование. Сохранения в файл на этом этапе ещё нет.

Второй коммит: «Реализованы Keeper и меню работы с конференцией».
