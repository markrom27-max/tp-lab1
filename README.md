# Этап 1 — классы конференции

Откройте ConferenceLab.sln в Visual Studio 2022. Выберите Debug x64 и нажмите Ctrl+F5.

Реализованы абстрактный Base, три производных класса, проверка ввода, исключение AppError и фабрика объектов. Программа вводит один объект, выводит его и создаёт независимую копию. Контейнер и файловое хранение добавляются на следующих этапах.

Первый коммит: «Добавлены классы участников и программы конференции».
