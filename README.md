# Этап 3 — файловые операции

Добавлены save/load в Base и производные классы, полное сохранение и восстановление Keeper через файловый поток, методы работы с файлами в Conference. Пункты меню 8 и 9 сохраняют и загружают данные. Загрузка выполняется через временный объект. Есть проверки метки формата, типов записей, количества, полей и лишних данных.
